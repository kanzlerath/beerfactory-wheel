# Beer Factory · Колесо подарков

Мобильный **демо-прототип** Telegram Mini App для ресторана-пивоварни Beer Factory.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Для деплоя подойдёт Vercel (Next.js).

## Сейчас реализовано

- адаптивный интерфейс в фирменной палитре (жёлтый, красный, зелёный и кремовый);
- колесо с анимацией, экран выигрыша;
- история тестовых выигрышей в localStorage;
- раздел правил и экран подарка;
- поддержка мобильной безопасной области.

## Важно — НЕ ГОТОВО ДЛЯ БОЕВОЙ АКЦИИ

В этом прототипе выбор приза выполняется браузером, а данные сохраняются локально. Промокоды `DEMO-XXXX` не действуют. **Не включайте выдачу настоящих призов**, пока не будут добавлены серверный розыгрыш, валидация Telegram initData, учёт попыток в БД, правила вероятностей и транзакционное погашение.

Логотип в текущей версии — облегчённая интерфейсная реплика знака. Для точного соответствия макету добавьте в `public/` оригинальный SVG/PNG фирменного логотипа и подключите его вместо компонента `Brand`.

Бот: [@beerfactorywheelbot](https://t.me/beerfactorywheelbot). URL Mini App настраивается отдельно через BotFather, после деплоя.
